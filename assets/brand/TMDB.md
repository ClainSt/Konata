# TMDB attribution asset

Official blue short logo, downloaded unchanged from TMDB's own developer documentation on 2026-11-05:
https://files.readme.io/29c6fee-blue_short.svg

The developer FAQ (https://developer.themoviedb.org/docs/faq) embeds this exact asset as its TMDB logo and links to the approved logo page:
https://www.themoviedb.org/about/logos-attribution

tmdb-logo.svg is the original. tmdb-logo.png is a transparent raster rendering at width 820, preserving its colors and aspect ratio. No runtime network request or extra Flutter dependency is required. Display with BoxFit.contain and without a color filter. Keep TMDB branding less prominent than CCPlayer branding.

Required notice in Settings → About:
This product uses the TMDB API but is not endorsed or certified by TMDB.

Website: https://www.themoviedb.org
The logo remains the property of TMDB; it is included for attribution.
