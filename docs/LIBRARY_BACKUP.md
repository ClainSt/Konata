2026-11-06续阶段：当前schema18导出另含身份修订、事件本地来源证明和Bangumi章节映射；只读检查兼容15/16/17/18。设备运行身份和序号继续排除。尚无完整恢复，恢复时不能把旧来源证明当作新设备证明，不能复制运行设备身份；备份可能含待物化撤回，不能直接取watch_events用于网络同步，应经专用exportEvents处理。

状态：导出和只读检查均已接入“设置 → 记录与同步”；专项测试通过。**恢复/导入未开放**。

## 范围

- ZIP 内的 `manifest.json` 包含当前 SQLite schema v17 的作品、媒体源索引、视频记录、播放进度、人工关联、缓存详情、修复归档、逻辑剧集确认记录及观看事件。只读检查继续兼容 v15、v16 备份；v17事件需通过字段及完整因果图校验。设备运行身份和计数器不导出，未来恢复必须生成新设备身份，不能复制运行身份造成事件ID冲突。
- 自定义封面仅包括以内容 SHA-256 命名的 `original_*.png` 与 `crop_*.png`，单项最多 32 MiB，总计最多 512 MiB；不包含网络图片缓存。
- 备份不读取 WebDAV/SMB/NAS 或视频正文、不计算视频哈希、不修改原媒体。
- 用户安全存储中的 TMDB 认证、WebDAV/SMB 密码不导出。历史数据库密码字段设为 null，媒体源 URL 的用户信息和常见敏感查询字段被清除。
- 仍包含媒体库名称、源路径、作品名称和观看记录等个人信息。**备份文件不是加密文件**，不应公开分享。
- 当前 UI 使用跨平台 FilePicker bytes 保存，超过 64 MiB 将给出提示而不是将全部 ZIP 读入应用内存。核心导出服务不受该 UI 限制，后续可以按平台增加流式保存。

## 校验

`LibraryBackupInspector.inspect` 只读检查 ZIP 格式、版本、schema、各表字段类型、引用关系、预期文件路径、尺寸上限和自定义封面的 SHA-256，返回作品、文件、来源、历史、封面数量。绝不解压到外部目录，也不写数据库。
