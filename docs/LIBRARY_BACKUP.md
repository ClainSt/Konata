# 媒体库备份与恢复

2026-11-08：恢复属于核心能力，始终可用。入口为“设置 → 记录与同步 → 从备份恢复”。

## 范围与使用

- 预览当前媒体库数量、备份时间及作品/文件/来源/记录/封面数量，明确确认后替换当前库，不合并。取消不写入。
- 恢复作品与隐藏状态、源路径和文件索引、断点进度与观看区间、手动完成状态、人工剧集关联、详情及旧角色自定义数据、修复归档、逻辑剧集确认、观看事件、身份修订与 Bangumi 章节映射。
- 恢复手动封面及原图、主题模式、主题色、语言和看完阈值。缺失的这些设置恢复默认值，其他本机设置保留。
- 兼容格式版本 1、数据库 schema 15–18；旧备份没有的新表留空。运行设备身份与事件序号不导入，后续事件使用新身份，旧事件不会被冒认为本机新证明。网络导出仍须经过 WatchEventStore.exportEvents。

## 回退与中断

1. 先复制 ZIP 至应用专用暂存目录，校验并解压。预览和写入使用同一副本。
2. 检查格式、表名、列类型、必要字段、事件因果图、媒体/进度引用和封面 SHA-256。主键/唯一约束冲突会使整体事务失败。
3. 写入前自动生成恢复前 ZIP，应用数据目录 restore-backups 中保留最近两份。界面的“恢复前的备份”可预览并恢复它们。只轮换程序专用目录中的自有备份，不删除用户导出的文件。
4. 数据库采用整体事务。设置写入失败也会回滚库表并还原设置；失败时清理新导入封面，保留既有封面与用户资源。
5. 小型恢复日志记录新旧设置和新增封面，数据库提交状态决定启动时应用哪一组设置。初始化先处理日志，再加载设置和展示媒体库。启动清除本应用遗留暂存目录。
6. 扫描中拒绝恢复；写入时显示不可关闭的进度对话框并占用扫描忙碌状态。当前没有运行中的账户同步传输引擎；未来引入时须接入该维护窗口。

恢复提交后按所有作品（包括隐藏作品）校正网络图片的归属，清除已不存在作品的缓存引用，保留共享图片与自定义原图/裁剪图。清理失败只保留重试日志，不回滚已提交媒体库。日志状态 2 表示设置已完成，此后重试仅清理缓存，不再覆盖用户随后修改的设置。

## 路径与凭据

- 备份包含索引，不包含视频、网络图片缓存、旧插件文件及本机扩展偏好、安全存储中的刮削密钥与来源密码。
- 导出和恢复都清除来源 URL 用户信息及常见敏感查询字段，清空用户名/密码。恢复来源被标记为需要重新确认凭据，不会因来源 ID 相同而沿用旧密码；重新填写密码后解除标记。旧安全存储条目不会在恢复时删除。
- 保留根路径与相对文件路径，恢复期间不扫描、不连接来源、不下载图片。跨设备路径不保证可用，须在“编辑来源”重新选择根目录、授予 Android 目录权限或填写网络凭据。同一文件树结构可继续使用原索引和进度。
- 本机播放器配置、解码偏好、目录授权和扩展设置不会被便携备份覆盖，避免跨平台画质配置互相套用。
- 备份不加密，仍包含路径、标题和观看记录。

## 成本与限制

- 无新增依赖，复用 archive、SQLite、SharedPreferences、FilePicker。无新增后台任务、网络请求或视频解码；不改动 MPV、字幕和渲染链路。
- 输入 ZIP 上限 600 MiB，manifest 64 MiB，单张自定义封面 32 MiB、合计 512 MiB。磁盘需同时容纳暂存副本、解压封面、数据库日志及最多两份恢复前备份。
- 封面逐张处理；manifest 和数据库快照仍整体解码。大型媒体库的一次性内存及读写峰值尚未实测，不宣称性能收益。
- 既有导出界面使用 FilePicker bytes 保存，ZIP 超过 64 MiB 会提示超限；恢复端可读取符合上述限制的更大备份。流式大文件导出尚未实现。
- 新增维护成本集中在事务、恢复日志与自动备份轮换。

## 验证

- test/library_backup_restorer_test.dart：全表往返、schema 15–18、自动备份还原、数据库/设置失败回退、启动中断恢复及非法数据。
- test/library_backup_restore_flow_test.dart：真实设置页面中的取消、确认及恢复前备份还原。
- integration_test/library_backup_restore_test.dart：独立验证应用的临时数据库，设备文件、SQLite 和设置存储。系统文件选择器使用测试替身，因此不将此测试宣称为系统选择器验收。
- 测试不覆盖实际用户媒体库。构建与实机结果另记于 release/validation/backup-restore-20261108/verification.json。

2026-11-08 验证结果：静态检查通过；全量测试 366 通过、8 跳过；平板隔离恢复往返通过（4230 ms，为小型测试样本和界面流程耗时，不代表大型媒体库性能）。实际 Release 验证包的系统 ZIP 选择、恢复预览与取消也已通过，未覆盖用户媒体库。Windows 便携目录相对上一验证包增加 30,698 字节，Android arm64 APK 增加 76 字节；无新增依赖。两端产物和校验值见 verification.json。正式签名发布及大型库性能未验证。
