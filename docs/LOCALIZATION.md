# 界面语言

使用 Flutter 标准 `gen-l10n`，资源在 `lib/l10n/*.arb`，入口 `l10n.yaml`。新增文字时在英文模板及简繁体资源补齐；运行 `flutter gen-l10n`，不要直接编辑生成的 `app_localizations*.dart`。

- 系统、简体、繁體、English 四个设置选项；默认跟随系统。
- `app_zh.arb` 是 Flutter 要求的中文基础回退，内容与 Hans 一致；Hant 独立翻译。
- 不支持的系统语言回退 English；系统优选列表中存在支持语言时使用该语言；中文显式 Hans/Hant 脚本优先于地区。
- `AppLanguage` 只负责界面偏好；不修改作品名称、元数据缓存、TMDB 请求语言或媒体源。
- `context.l10n` 读取应用的生成资源；独立组件在未安装 delegate 的宿主下使用简体资源回退，不维护另一套翻译表。

## 当前覆盖

已接入：设置主体、主题/语言控件及提示、应用导航、播放记录管理、版本选择、TMDB API 获取教程、TMDB 凭据设置及结果提示、TMDB ID 说明、服务地址表单与连接状态、CCPlayer 自有播放器按钮/错误提示/音轨字幕选择、媒体源添加/编辑/移除、目录浏览与搜索选择、扫描进度及基础媒体库工具栏。TMDB 署名中的官方英文声明保持原文。

已接入隐藏/恢复管理与移除确认、手动搜索绑定、资料编辑校验、角色排序、封面选择及裁剪。作品名称、搜索结果和来源标签保留原始内容；操作与错误提示使用当前界面语言。

详情页已接入操作菜单、演职员/角色标题、集数/版本数量、正片/特典、筛选、播放状态和简介展开操作。数量通过 ARB 参数及英文复数规则显示；元数据内容与特典筛选内部值保持原样。正片/特典标签按文字宽度展开并保持单行；超出可用区域时横向滚动，不缩小字号或换行。

内置移动端滑动跳转提示通过公开的 seekIndicatorBuilder 接入三语，普通/全屏共用 SeekIndicator；单行按内容扩宽，超出可用区域时横向滚动。日志导出标题及 TMDB 链接失败提示已接入资源。

内置双击跳转提示已通过本地 media_kit_video 2.0.1 的可选 seekDurationLabel 接口接入三语；普通/全屏共用资源，左右两个提示均保留累计跳转行为。具体补丁与许可证见 packages/media_kit_video/CCPLAYER_PATCH.md。显示保持12px和单行，超宽横向滚动。

待接入：底层异常及其他剩余提示；播放器真机兼容检查仍待完成。不能将本阶段标作完整国际化。

服务诊断使用结构化结果（状态/错误类型/技术详情），UI 按当前语言显示状态，不解析中文字符串；技术详情保留 HTTP 状态码与 host，不输出完整请求 URL、凭据或原始异常消息。语言切换无需重新请求。播放器选择菜单保留媒体原始标题/语言/编码；仅翻译自动选择、关闭和操作提示。文件与媒体内容不翻译。

设置左栏按当前语言及文字缩放测量最长标签；宽度不足以同时保留内容区时使用已有紧凑分类布局。顶部导航标签按文字测量宽度，单行显示；极窄或极大字号下在独立导航区域横向滚动，操作按钮保留。

目录浏览将面包屑、目录勾选和项目数合并在一行；面包屑横向滚动并保留各级返回，不重复显示另一行路径。扫描摘要和目录列表在同一滚动区域，窄屏/大字号时目录统计显示在名称下方。技术路径与用户名称不翻译。

后续迁移应优先使用同一套 ARB 类型化资源；动态数量/插值使用 ARB placeholders/plurals。播放路径、文件名、作品资料和用户自定义名称不翻译。

## 英文文案规则

英文按使用场景重新措辞，不逐字翻译中文。菜单、按钮和标签优先使用常见短词或短句，例如 `Metadata`、`Theme`、`System`、`Choose version`。说明只保留必要信息；删除、隐私、认证类型等会影响用户决定的信息必须保留。避免中文句式、重复上下文和生硬术语。
