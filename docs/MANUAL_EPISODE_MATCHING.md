# 手动剧集纠错

详情页更多菜单中，“编辑元数据”下方提供“手动编辑”。输入 TMDB 作品名或 ID，选择电视剧、季（包括季 0 特别篇），点击文件后选择对应集。也可以暂不改动，或归入其他。更换季不会清除已选择的文件匹配，可一次保存多个季的修改。

保存前只保留页面草稿；取消不写数据库。保存使用一个 SQLite 事务，同时更新作品绑定、文件分类/季/集、人工覆盖与撤销记录，删除旧详情缓存并重新加载。原始文件名、路径和播放进度不改动。后续扫描沿用人工覆盖；详情取集名/剧照时优先人工季/集，不再让 CM、文件夹季号等自动线索覆盖纠错。

同一 TMDB 作品可只纠正部分文件。切换到不同 TMDB 作品时必须为本作品的全部文件指定匹配，避免未确认文件被连带套用新作品资料。本功能按当前作品管理文件，不支持同一作品内的文件分别绑定到多个不同 TMDB 作品。

中文角色/声优名优先读取 Bangumi 的 name_cn；列表缺失时补查角色/人物详情中的中文名和 infobox 简体中文名。没有中文名时保留原名，不猜译。详情缓存版本提升为 10，使旧缓存能重新获取补充资料。原名另存供非中文界面使用，演员详情按人物 ID 去重请求。网络请求沿用现有缓存和并发预算。

依据：[Bangumi 官方 API 定义](https://github.com/bangumi/api/blob/master/open-api/api.yml)、[TMDB 季详情接口](https://developer.themoviedb.org/reference/tv-season-details)。

自动测试覆盖季 0 选择、文件选集、中文名补查、保存事务失败回滚、重扫保留人工匹配及观看进度保留。真实服务器数据、Windows/Android 真机交互尚未验证；本次未构建安装包。
