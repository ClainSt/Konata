# CCPlayer — 媒体源与刮削范围（2026-11-04）

## 这次修复

1. **文件夹左侧复选框**：点击复选框加入或移除刮削范围；点击名称继续浏览。原有“单部作品/作品合集”按钮及右侧菜单已移除。支持同一个媒体源多个不重叠范围；勾选父目录会取代其已选择的子目录，反之亦然。
2. **自动识别**：根据选定目录及其内部文件分布、TMDB-ID、发行年份、季度、SP/BD 等目录层级进行分组。目录含明确 TMDB-ID 时优先关联该目录；不确定的分组标记“待复核”。不会把 CDs、Scans 当作首版视频内容。
3. **媒体源编辑**：媒体源卡片铅笔图标可修改名称、URL、本地路径、用户名和密码，支持“测试连接”。不提供额外匿名模式复选框，用户名、密码留空时直接匿名访问；密码默认不显示、不更改，提供单独清除操作。固定 sourceId，保留索引、人工绑定和观看位置。更改根路径后原文件可能不可用，需自行验证、重扫。
4. **匿名 WebDAV**：用户名及密码都可留空；这时不发送 Authorization 请求头。目录浏览继续支持 Basic/Digest 认证挑战（测试服务器已覆盖）。CD2 服务器仍按实际的匿名权限工作。
5. **TMDB 双认证**：设置界面显示「访问令牌」或「API Key」，前者发送 Bearer Header，后者仍使用 TMDB v3 API 的 `api_key` 参数。凭证分开安全保存，支持测试连接。元数据仅使用 TMDB 与 Bangumi。

## 操作流程

1. 在媒体源页面点击 **添加媒体源**，已有源可点击 **编辑图标**。
2. 添加 WebDAV 时，若 CD2 已开放匿名访问，用户名和密码直接留空；否则输入凭证。
3. 点击媒体源进入目录浏览，逐级查看文件夹。点击文件夹**左侧复选框**勾选，点击文件夹名称进入。
4. 可以勾选 `动画-单作品` 这个上级目录，也可以单独勾选它下面的某几部动画。对目录类型不需要任何手动选择。
5. 在底部检查本次选中的文件夹，并点击 **扫描已选目录**。成功索引后自动清空复选框并直接开始 TMDB/Bangumi 刮削；不会在底部弹出要求手动刮削的提示。右上角的「扫描进度」取代刷新按钮，点击可查看每一个已访问文件夹与该目录直接包含的视频文件数量，并显示自动刮削进度或错误。已索引作品、人工关系和观看记录均保留。遇到「待复核」可从详情页「···」→「编辑元数据」手动修正。

## 边界与验收状态

- 浏览与扫描只执行本地目录枚举或 WebDAV 只读 PROPFIND，不会修改云盘、下载正片、重命名或移动媒体。
- 不会自动扫描用户未勾选的目录，也不会自动删除人工锁定作品。
- 自动分组仍是按目录与文件名推断，不保证复杂 BDRIP 命名的正确率；特别是多季度、系列与外挂字幕需要真实样本回归。
- WebDAV 匿名访问、Digest 浏览、中文文件名及 Depth:1 目录自身响应过滤已有模拟服务器测试；另有本地扫描后自动刮削和每目录视频数的回归测试。**没有使用真实 CloudDrive2 凭证进行验证**，真实连接尚待用户验收。
- 当前播放代理的 Digest、跨设备同步、Bangumi 观看记录同步、全库无人值守 TMDB 自动刮削和 Windows 外部 MPV 仍未完整实现。打开详情页可按已有 TMDB/Bangumi ID 获取更多公开资料。本轮修复不等于首版最低要求全部完成。
- HTTP WebDAV 可能暴露传输内容及 Basic 凭证，实际使用建议 HTTPS 或受信任的局域网环境。
- Windows 构建复用独立项目内 `packages/flutter_secure_storage_windows` 的 Dart FFI Credential Manager 适配，避免构建环境缺少 ATL。
