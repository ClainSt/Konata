# NipaPlay Personal 详情页与视觉移植

CCPlayer 的初版界面暂时保持 NipaPlay Personal 视觉语言，后续再设计自己的 UI。参考的源文件位于用户本机的 `D:\Codex-Projects\Anime\NipaPlay-Personal\lib\themes\nipaplay\widgets\library_anime_detail_page.dart` 等处，CCPlayer 保持独立工程，并未将原项目的大量媒体服务器、播放器或状态管理依赖整体引入。

## 初版已经接入

- 原版浅色/深色主题的色彩方向、绯红强调色、Windows 微软雅黑、简体中文文本样式以及圆角组件（目前 CCPlayer 默认使用浅色模式）。
- 详情页：全屏背景渐变、海报、标题、评分、发行年份、集数、作品标签、简介展开/收起、顶部关联管理。
- 内置播放：开始播放、继续播放、从头播放、正片/特典标签、横向剧集封面和完整列表、文件级观看进度状态。
- 元数据：从 TMDB 获取剧集标题及剧照、海报和背景，从 Bangumi 获取角色及声优、评分、简介与标签（公开资料，不使用弹弹play元数据）。
- SQLite 缓存：按 TMDB/Bangumi 关联身份缓存详情 JSON，重绑后缓存自动失效；网络失败保留缓存及本地索引。
- 文件关联管理：正片/特典、集数及同媒体源内作品归属人工锁定，重扫优先人工覆盖，支持撤销最近一次关系修改。
- 保留原有云盘文件名与目录只读扫描，不修改媒体文件。

## 同步修复的问题

- 作品简介下方的重复元数据绑定按钮已移除；详情页只保留顶部关联管理入口，搜索绑定功能在关联管理内。
- WebDAV 编辑直接输入「用户名（可留空）」及「新密码（可留空）」，无匿名复选框或更改密码复选框。密码默认不显示、不改动；右侧清除按钮可明确清空旧密码，用户名和密码同时为空即匿名。
- 文件夹勾选仅为一次扫描队列，成功扫描后清空、失败保留；再次进入浏览页无默认勾选，原媒体库不受影响。
- TMDB 设置的认证方式和输入框文字只显示「API Key」，底层 v3 API 认证机制保留。

## 与完整 NipaPlay Personal 的差异

- 本阶段移植其**详情页结构和关键交互**，并非将原 978 行组件及全部依赖原样复制。
- 复杂季度、绝对集数与特典的 TMDB 映射仍需更多真实 BDRIP 样本验收。
- 角色姓名中文化遵循 Bangumi 返回字段，尚未实现 NipaPlay Personal 的逐角色异步汉化补全。
- TMDB/Bangumi 元数据以数据库 JSON 缓存，图片链接目前仍为网络加载，未实现完整离线图片文件缓存。
- 完整 UI 首页结构、设置系统、TV 焦点模式、Bangumi 观看记录同步以及全量自动刮削都尚未达到 Personal 版本的同等完整度。
- Windows 外部 MPV 和 WebDAV Digest 播放代理属于播放器工程，暂不在这次详情页移植中宣称完成。

本轮回归以代码检查、Flutter 测试和 Windows Release 构建为标准；真实 CloudDrive2 播放与 Android 真机画面仍需实测。
