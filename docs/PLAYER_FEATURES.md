# 播放器扩展：双端构建通过，回归待恢复

本阶段源码包括：

- 顶部栏以下整个区域作为黑色播放区域，移除外层重复进度条和播放控制。
- 普通/全屏视频控件内提供统计数据、时间轴预览、播放暂停、字幕、音轨和章节入口；菜单功能暂缓。
- 全屏回调隐藏应用级媒体库/媒体源导航，并沿用原生全屏调用；退出后恢复。
- 章节直接读取 mpv chapter-list/count、逐项 time/title；点击使用已有 seek 接线，不从文件名伪造章节。
- 字幕按标题/语言标记识别简体、繁体、日语和未标明简繁的中文，优先简体；不要求视频必须含日语字幕。
- 音轨优先 FLAC、ALAC、TrueHD、PCM 等无损编码；DTS 只有明确 MA/Master 标记才视为无损。用户手动切换后停止自动干预。
- 统计数据显示实际编码、尺寸、帧率、硬件解码、丢帧、音频采样/码率、缓冲和音画偏差；不可用项目单独回退，不影响其他数据。
- 时间轴标记章节节点，悬停/拖动预览展示章节名、画面和时间；靠近节点时按节点时间取帧。独立静音解码器取图，不使用主播放器 seek 来捕获预览；200ms 防抖、过期请求淘汰、24张内存缓存。仅在用户启用预览后请求帧。

依据：[mpv 官方属性说明](https://mpv.io/manual/master/)，以及当前 media_kit 1.2.6 / media_kit_video 2.0.1 的本地源码。seekBarOverlayBuilder 是本地依赖补丁提供的可选接口。
