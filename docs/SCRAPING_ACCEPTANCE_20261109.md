# 刮削、网络与图片验收（2026-11-09，2005 候选）

本轮属于核心媒体库能力；角色资料仍遵守既有可选功能资源作用域。无新生产依赖、数据库版本升级、媒体移动或重命名。不重复已通过的播放测试，不使用电脑前台自动操作。

## 已确认规则

- 文件夹与视频文件指向不同作品：冲突文件待归类。
- 中文、日文、英文、罗马音仅按供应商正式名称/别名匹配；唯一且年份、季数无冲突才自动写入。
- 混合目录在媒体库内虚拟归类，保留文件 ID、路径和进度；未知文件支持同来源批量选择作品或新建用户标题，手动关系可撤销且重扫保留。
- TMDB ID 定位条目，年份/季数进一步确定季。同一年多季不能凭年份猜测。
- 用户明确批准 WMV 加入索引、刮削；不将索引通过等同于 WMV 播放验收。

## 修复与成本

- 对握手阶段 `Connection terminated during handshake` 最多重开一次，不关闭证书验证，不重试认证错误。服务器故障记忆有恢复探测，用户服务器/代理配置保持生效。
- 角色卡片和已补齐姓名渐进持久缓存，失败字段以后重试；每次姓名补全并发 2、预算 9 秒。图片无需等待姓名全部补齐。作用域内复用连接，结束批次/关闭功能时释放。
- 刮削同批缓存最多 128 个响应，每个编码后不超过 64 KiB，未完成请求去重；不缓存失败。这个约 8 MiB 是编码载荷上界，并非 Dart 实际堆占用测量。
- 文件身份去重、资产按作品一次分组；最多两部作品并行，所有网络共享现有请求预算。按目录 SQLite 事务批量索引，取消回滚当前目录，已完成目录保留。
- 未锁定旧匹配不再作为原始 ID/年份证据；身份变更清除不再可信的自动海报和供应商 ID，保留用户封面及手动资料。已虚拟分组的复刮将不确定文件单独放回待归类，保护手工锁定目标。
- 没有默认下载大型资源、没有新增常驻定时服务。CPU/GPU、电量、系统内存和长期缓存压力未测；最终包大小以 release/latest-build.json 为准。

## 限制与建议

不保证任何国家、网络、上游服务始终可用。当前测试发生于本机现有网络，曾出现独立客户端也可复现的 TLS 握手中断；保留失败记录，没有通过放宽证书安全或隐藏失败使测试通过。

上游搜索候选超过上限会切换另一个可验证供应商或保留待确认。建议以后根据真实未匹配清单增加有证据的解析规则，避免为提高表面命中率增加模糊自动匹配。Catalog 仍较大，后续随实际需求渐进拆分，不在此次引入新框架。

虚拟归类仍使用现有表结构；保留旧源码提交及用户数据副本供回退。按发布规则清理旧二进制后，如需旧版程序须从原提交重新构建。发布清理前必须迁移并核对旧便携目录中的 userdata，不能把它当作纯旧二进制删除。
