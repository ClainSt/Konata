# SMB 媒体源

添加媒体入口参考 NipaPlay Personal，分为本地媒体和网络媒体。网络媒体提供 WebDAV、SMB。

SMB 地址格式为 `smb://主机/共享名`，可包含共享内的子目录。使用标准 445 端口。凭证单独填写，用户名可写为 `域\用户名`，密码沿用项目的系统安全存储，不写入媒体库数据库或 URL。

SMB 接入与 WebDAV 相同的目录浏览、选择扫描范围、扫描、刮削、视频和字幕读取流程。播放器通过本机回环地址读取 SMB 内容，支持 HTTP 字节范围请求以便跳转，不会先下载完整视频。

客户端来自本机 NipaPlay Personal 的 `third_party/smb_connect`（0.0.9），保留在 `packages/smb_connect`，原始许可见该目录的 `LICENSE`。本项目仅调用其读取操作；当前客户端的协议支持以该库为准（SMB 1 / 2.0 / 2.1），不宣称支持强制 SMB3 加密的服务器。

已用模拟连接验证中文目录、适配器、连接清理与播放范围请求。尚未在真实 NAS/SMB 服务器上完成连接和播放验收。
