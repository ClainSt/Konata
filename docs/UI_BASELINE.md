# CCPlayer 当前视觉基准

当前阶段整体沿用本地 NipaPlay Personal 的视觉语言，后续再考虑切换为 CCPlayer 自有设计。

- `lib/ui/nipaplay_style.dart` 是全应用共享的主题入口：粉色强调色、中性色背景、中文字体和统一的弹窗、列表、输入框、按钮及菜单。
- 顶部左侧为媒体库、媒体源；右侧为日夜切换、设置和桌面窗口控制。桌面空白区域支持拖动和双击最大化。
- 设置采用 NipaPlay 的分类布局，只提供已经实现的设置：外观、TMDB API 和关于。窄屏改为顶部分类。
- 主题支持日间模式、夜间模式、跟随系统，选择保存在本机。右上角快捷切换会选择固定的日间或夜间模式，可在设置中恢复跟随系统。
- 媒体库、媒体源、目录浏览、详情、编辑弹窗和播放控制共用上述主题。播放画面和视频控件保持适合观看的高对比度，进度使用相同粉色。
- 本次没有添加 NipaPlay 中尚未在 CCPlayer 实现的设置项。

Windows 发布版本需要整个输出目录中的 DLL 和 data 文件夹，不能只复制 exe。

## 2026-11-05 界面更新

- Windows 顶栏左侧使用等宽媒体库/媒体源导航，右侧为等距的主题、设置和窗口操作；Android 使用底部主导航。
- 外观设置支持日间、夜间、跟随系统，以及红色、柔粉色、浅蓝色强调色，均保存到本机。
- 主题下拉菜单优先向下展开，空间不足时向上；菜单宽度及文字缩进与选择框保持一致。
- 媒体库数量、搜索、添加入口采用自适应工具栏；媒体源卡片只提供编辑、浏览及移除，扫描由目录浏览中的勾选流程发起。
- 详情页固定操作栏透明；没有缩略图的特典使用淡化作品图片和类型编号，中文标题显示在卡片下方。未知类型保留清理发布信息后的文件名，悬停可看原名。
- 本地验收包保存在 release/，不提交到源码仓库。
